订单管理 PRD

客户小程序研发详细需求规格 · V2.0 · 2026-09-08

统一定义迷你仓、迷你箱和商品订单的列表、筛选、详情、状态映射、动态操作、时间线、金额与资产展示，作为各业务模块的客户侧订单主入口。

属性内容
文档编号MP-ORD-01
适用端客户小程序、运营后台、工单小程序及领域服务
范围订单总览、分类和组合筛选、搜索和排序、订单卡片、三类详情、状态聚合、允许操作清单、物流/合同/保单/支付资产入口、取消规则、客服上下文。
不在本模块范围各领域内部状态流转、支付渠道收单、合同模板维护和工单执行；订单中心消费这些服务的权威结果。

1 目标与边界

1.1 本期范围

订单总览、分类和组合筛选、搜索和排序、订单卡片、三类详情、状态聚合、允许操作清单、物流/合同/保单/支付资产入口、取消规则、客服上下文。

1.2 不在本模块范围

各领域内部状态流转、支付渠道收单、合同模板维护和工单执行；订单中心消费这些服务的权威结果。

1.3 角色与系统责任

角色或系统职责
客户浏览、选择、签约、付款、提交申请、查询进度
客户小程序采集意图并展示服务端状态，不自行决定价格、库存、资格或审批结果
运营后台维护主数据、价格、库存、可操作项、审批、异常处理和人工改派
工单小程序承接送取、验收、搬仓、清仓等线下任务，回传节点、附件和异常
领域服务保存订单、租约、箱体、预约、支付与合同的权威状态并发布事件

4.8 迷你仓订单详情：状态流转与操作

业务状态客户文案详情重点允许操作流转与失败处理
仓位已锁定 / 待签约待签约仓位锁定倒计时、报价版本、合同摘要签署合同, 取消订单签署成功→待付款；锁定过期→已取消；签署失败停留并可重试
待付款待付款应付明细、支付截止、合同已签标识付款, 取消订单支付发起→付款确认中；取消后释放仓位，已扣款则转退款
付款确认中付款确认中支付渠道、交易号、最近查询时间刷新付款结果, 联系客服回调成功→开仓生效中；明确失败→待付款；未知结果禁止再次支付
开仓生效中开仓生效中租约、合同、门禁、保单四项生效进度刷新进度, 联系客服全部成功→服务中；部分失败→异常处理中并创建后台补偿任务
服务中租用中门店仓位、租期、下次付款、门禁状态仓门开锁, 续租, 申请转仓, 申请退租各动作按资格返回；发起变更后详情进入对应子流程且互斥动作隐藏
即将到期即将到期剩余天数、续租报价提示、最早退租日续租, 申请转仓, 申请退租续租成功→服务中并更新到期日；到期未续→逾期或已完成，按合同策略
续租处理中续租处理中方案版本、补充协议、应付与生效进度签署续租协议, 支付续租费用, 查看进度签约→待付款→生效中→服务中；失败停留原租约并展示可恢复动作
转仓处理中转仓处理中审批、费用、目标仓锁定、排期、搬仓工单修改后重新提交, 支付转仓费用, 查看进度, 取消转仓审批/付款/排期/搬仓逐段推进；验收及门禁切换成功→服务中并替换仓位
退租处理中退租处理中清仓预约、验收证据、结算版本、退款/补款修改预约, 确认结算, 支付补款, 查看退款进度验收→结算→退款/补款→已完成；验收前按规则可撤销回服务中
逾期 / 服务受限逾期或服务受限欠费账期、金额、限制原因、宽限期支付欠款, 联系客服清欠成功→服务中/即将到期；门禁是否保留由服务端单独返回，不由前端推断
已完成租约已结束结束原因、结算、退款、历史合同与门禁失效时间查看关联资料, 再次购买终态；仅允许查看历史或再次下单
已取消 / 异常处理中已取消或处理异常取消原因/退款进度，或异常节点/跟进编号查看退款进度, 重试, 联系客服取消为终态；异常按补偿结果回原流程或进入人工处理

迷你仓租用中状态以图4-3为验收基准。动作缺失时按服务端允许操作清单隐藏，不保留空白占位。

4.9 迷你箱订单详情：状态流转与操作

业务状态客户文案详情重点允许操作流转与失败处理
待签约待签约套餐、箱数、地址时段、合同摘要签署合同, 取消订单签署成功→待付款；资料失效要求重新确认订单
待付款待付款应付、合同状态、送箱时段保留倒计时付款, 取消订单支付确认→待安排送箱；取消释放时段，已扣款则进入退款
付款确认中付款确认中渠道交易、查询时间、时段保留说明刷新付款结果, 联系客服成功继续首次履约；失败退回待付款；未知结果禁止重复扣款
待安排送箱待安排送箱预约地址/时段、箱数、履约单、取消截止查看进度, 修改预约, 取消订单生成送箱工单→空箱配送中；超过取消截止不返回取消订单
空箱配送中空箱配送中司机脱敏信息、运单、预计到达、实时节点查看物流, 联系履约人员逐箱交付成功→空箱已送达；缺箱/拒收→异常处理中
空箱已送达空箱已送达已交付箱数、箱号、封条、收箱须知预约收箱至少一箱可收才可预约；提交后→已预约收箱
已预约收箱已预约收箱取箱地址/时段、待收箱清单、封条确认修改收箱预约, 取消收箱预约, 查看进度到达取箱→满箱取件中；截止前可改期/取消
满箱取件中满箱取件中逐箱扫码、封条校验、运单与异常查看物流, 联系履约人员全部收取→入仓验收中；部分失败保留未收箱并标记异常
入仓验收中入仓验收中逐箱验收、照片、箱号/封条/库位绑定查看进度, 联系客服全部合格→在仓存放；损坏或封条异常→异常处理中待客户/后台确认
在仓存放在仓存放箱体总数、逐箱库位、租期、运输权益、活动任务召回取物, 结束租用, 查看运输记录召回选中箱体→取物配送中；退租需覆盖所有未终止箱体
取物配送中取物配送中召回箱体、运单、预计到达；未召回箱仍显示在仓查看物流, 联系履约人员签收→箱体在客户处；拒收/丢损→异常处理中，不得覆盖首次履约旅程
箱体在客户处箱体在客户处在客箱体、返仓截止、剩余运输权益预约返仓, 结束租用预约返仓→已预约返仓；逾期按后台计费策略生成费用
已预约返仓 / 返仓运输中返仓处理中返仓时段、逐箱清单、工单与运单修改返仓预约, 查看物流收取→运输→入仓验收→在仓存放；部分箱失败按箱体保留状态
结束租用处理中结束租用处理中最终取物、空箱回收、损坏/缺失、结算与退款确认结算, 支付补款, 查看退款进度全部箱体回收且结清→已完成；缺箱/欠费保持处理中
已完成 / 已取消已结束或已取消结束原因、历史箱号/运单/合同、退款查看关联资料, 再次购买终态；取消前已支付时持续显示退款进度
异常处理中履约异常异常箱体、节点、证据、处理编号、预计反馈时间重试当前可用操作, 联系客服后台或工单处理后回到原旅程节点；禁止前端直接跳过异常节点

4.10 动作执行契约

操作服务端准入客户端交互成功或失败结果
签署合同合同有效、锁定/预约未过期打开合同阅读与签名；签署中禁用返回重复提交签署成功刷新详情；失败保留签署任务并显示原因
付款及各类业务付款应付>0、支付窗口有效、无未知支付结果创建或复用支付意图；页面切后台后轮询权威结果成功进入确认/生效；失败可重试；未知只允许刷新
取消订单或取消服务服务端返回取消动作且未过截止二次确认并展示费用/退款影响；提交原因码释放仓位/时段/任务；已支付进入退款中，失败保留原状态
仓门开锁本人有效租约、门禁正常且动作未过期进入开锁模块执行定位、资格和凭证校验成功追加门禁时间线；拒绝不改变订单状态并返回原因
续租 / 申请转仓 / 申请退租租约有效且无冲突活动申请跳转对应申请页并传 租约编号、订单编号、订单数据版本创建成功回详情显示子流程；取消或失败恢复原租用状态
新建或修改预约对象可预约、时段有库存、未过改期截止选时段并返回 报价版本；改期展示旧新时段成功替换预约并同步工单；冲突刷新可选时段
召回取物 / 预约返仓选中箱体无活动任务且有运输权益/可付费逐箱选择、校验地址时段、展示权益扣减或费用成功创建独立旅程；部分箱体状态独立推进
结束租用无冲突召回/返仓，或服务端允许合并展示全部箱体、最终取物和预估结算，确认后提交进入结束租用流程；结清前不得停止计费或解绑箱体
查看物流 / 查看进度有关联运单、工单或子流程只读打开对应旅程并保留订单返回路径返回详情自动刷新；查看动作不改变业务状态
确认结算 / 支付补款结算版本有效且客户待确认/待补款展示费用证据与版本；确认或付款携带 结算单版本结清后继续终止；版本冲突刷新并要求重新确认
联系客服始终可用，严重权限异常除外传订单、状态、最后事件、异常编号和问题类型创建客服上下文，不修改订单；客服处理通过领域事件回写

4.11 详情刷新、并发与跨端回写规则

•

详情初始化并发请求基本信息、时间线和资产；基本信息失败显示整页错误，时间线或资产失败仅局部降级并可单独重试。

•

允许操作清单 必须包含 操作记录编号、结果编号、按钮文案、按钮样式、显示优先级、跳转页面、二次确认内容、操作失效时间、不可操作原因 和 操作清单版本；客户端只负责展示与提交。

•

同一订单出现多个客户待办时，按付款/签约、到期/违约、预约、一般服务的优先级确定主任务；其余进入‘更多操作’或关联服务卡片。

•

状态变化以领域事件为准；支付回调、工单回传、后台审批到达后递增 订单数据版本，并使旧页面写操作返回数据版本冲突。

•

迷你箱的订单状态是箱体与旅程的聚合展示；任何箱体处于异常或在途时，详情必须展示逐箱差异，不能只给一个笼统订单状态。

•

时间线节点必须包含 事件编号、履约旅程编号、业务对象编号清单、节点状态、发生时间、操作方类型、客户可见说明；内部备注和员工手机号不得下发。

•

从通知、客服或外链进入详情时先校验登录、订单归属和 业务类型；无权不可泄露订单是否存在。

•

页面每次重新可见、动作返回、支付回跳及子流程返回均刷新详情；轮询只用于支付确认和短时履约节点，退到后台即停止。

5 业务规则

•

列表默认按‘需客户处理优先、同类按业务进度、再按更新时间倒序’排序；服务端返回 服务端排序值，客户端不得仅凭中文状态推断。

•

搜索匹配订单号、商品、门店、仓位和服务端提供的 可搜索文本；输入300毫秒防抖，关键字最长50字符。

•

筛选支持业务类型、聚合状态和下单时间组合；切换业务类型后重置不适用状态，但保留关键词和时间条件。

•

列表使用游标分页，首次20条、后续20条；筛选变化取消旧请求，按 查询版本 丢弃乱序响应。

•

订单卡片字段固定为业务类型、订单号、标题、描述、状态、风险提示、3项关键指标和动态操作；缺失字段使用‘--’，不得伪造。

•

详情以 订单数据版本 做并发控制；从列表进入先显示快照并立即刷新，服务端新版本覆盖缓存。

•

所有按钮完全依据 允许操作清单 数组渲染，动作对象包含 结果编号、按钮文案、按钮样式、跳转页面、是否二次确认、操作失效时间、不可操作原因。客户端不得按状态硬编码越权动作。

•

写操作携带 幂等请求标识、订单数据版本 和 链路追踪编号；数据版本冲突刷新详情并提示状态已变化，禁止本地强改状态。

•

迷你箱必须同时展示‘首次履约’和‘召回与取物’旅程，后者不得覆盖前者；箱体状态按 箱体编号 独立展示。

•

金额区统一展示原价、优惠、服务费、保险、按金、应付、实付、退款和币种；无值不显示该行，但应付/实付必须有。

•

客服入口必须传 订单编号、业务类型、状态编号、最后事件编号 和客户问题预填，不允许客服页固定示例订单。

•

通知深链打开订单前校验登录和订单归属；无权、已删除或迁移订单显示明确错误并提供订单中心入口。

•

离线只允许读取最近缓存且标记更新时间；所有写操作禁止离线排队，以避免恢复网络后重复执行。

10 非功能与安全

•

百分之九十五的请求中，列表首屏不超过2秒、详情不超过1.5秒；长流程先返回受理结果，再异步更新进度。

•

敏感字段最小化展示，日志脱敏，下载资产使用有时效的安全下载地址。

•

所有状态变更记录前后值、操作者、来源端、原因码、时间和链路追踪编号。

•

支持简体中文、繁体中文、英文；日期、货币和地址按香港业务规范展示。

12 验收标准

•

验收项01 三类订单数量、列表结果和筛选条件一致，切换分类不会串数据。

•

验收项02 关键词可命中订单号、门店、仓位、箱号或商品名，清空后恢复当前分类全量。

•

验收项03 订单状态变化后，旧页面执行动作收到数据版本冲突并刷新为最新状态。

•

验收项04 服务端移除某个 允许操作 后，客户端刷新即隐藏对应按钮。

•

验收项05 迷你箱部分召回时，详情同时显示未召回箱体在仓和召回箱体配送中。

•

验收项06 迷你仓待签约订单展示合同和付款主操作；租用中订单展示开锁、续租、转仓、退租。

•

验收项07 待付款订单重复点击支付只复用或安全创建新的支付尝试，不产生重复扣款。

•

验收项08 符合条件的迷你箱取消后释放送箱时段；已付款订单显示退款处理中。

•

验收项09 订单详情所有时间来自服务端并按客户时区显示，原始时间保留协调世界时。

•

验收项10 接口超时、空列表、无网络、无权限、订单不存在均有独立可恢复页面状态。
